---

현재 등록된 모든 운영 콘텐츠(`content/` 아래)를 검토한다.
`docs/DATA_MODEL.md`, `docs/SOURCE_POLICY.md` 기준을 따른다.

다음 기준으로 감사(audit)한다.

1. source_level이 없는 콘텐츠 찾기
2. status가 없는 콘텐츠 찾기
3. last_updated가 없는 콘텐츠 찾기
4. 공식 규칙인데 출처가 불분명한 콘텐츠 찾기
5. K1/IDEA/CASE가 공식 기준처럼 작성된 곳 찾기
6. 같은 주제인데 서로 다른 기준 찾기
7. 서로 다른 숫자가 사용된 기준 찾기
8. 더 오래된 기준이 최신 기준보다 우선 표시되는 곳 찾기
9. 같은 내용 중복 찾기
10. 내용이 지나치게 추상적이라 현장에서 행동할 수 없는 항목 찾기
11. 사용자가 오해할 수 있는 표현 찾기
12. 질문은 존재하지만 답변이 없는 항목 찾기
13. 목차에는 있지만 콘텐츠가 없는 항목 찾기
14. 콘텐츠는 있지만 목차/검색에서 접근 불가능한 항목 찾기
15. 실제 사례와 정책이 혼동된 항목 찾기

확실하게 자동 수정 가능한 것만 수정하고,
의미 판단이 필요한 것은 review_needed로 표시한다.

어떤 정책도 추측해서 채우지 않는다.
