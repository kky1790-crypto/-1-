# content/ideas

`source_level: K1` (강윤의 현재 관점/제안) 또는 `IDEA` (검토 중인 아이디어)
콘텐츠만 이 폴더에 둔다.

이 폴더의 내용은 **절대 H1/M1처럼 공식 기준으로 표시하지 않는다**
(`docs/SOURCE_POLICY.md` 참고). UI에서는 "강윤 개인 의견" 또는
"검토 중인 아이디어" 배지를 항상 함께 노출한다.

작성 시 `content/_templates/rule.template.md`를 복사해서 시작하되
`source_level`을 `K1` 또는 `IDEA`로 지정한다.

> 현재 이 폴더에는 실제 콘텐츠가 없다. Phase 1 콘텐츠 설계 단계에서 채운다.
