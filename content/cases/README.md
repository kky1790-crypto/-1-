# content/cases

`source_level: CASE` (실제 과거 사례) 콘텐츠만 이 폴더에 둔다.

사례는 그 자체로 규칙이 아니다. UI에서도 항상 "과거 사례"로 표시하고
공식 기준과 혼동되지 않게 한다. 가능하면 `current_standard_ref` 필드로
현재 유효한 기준 문서(official/gangseo/magok)를 함께 링크한다.

작성 시 `content/_templates/case.template.md`를 복사해서 시작한다.

> 현재 이 폴더에는 실제 콘텐츠가 없다. Phase 1 콘텐츠 설계 단계에서 채운다.
