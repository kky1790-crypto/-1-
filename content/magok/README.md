# content/magok

`source_level: M1` (마곡점 공식 운영 기준) 콘텐츠만 이 폴더에 둔다.

해피니언 전체 기준(H1/H2), 강서 기준(G1), 강윤 개인 의견(K1)과 절대 섞지
않는다. 마곡점 고유의 운영 기준(정액권, 시술 흐름, 컴플레인 처리 기준 등)이
여기 들어간다. 메타데이터 스키마는 `docs/DATA_MODEL.md` 참고. 작성 시
`content/_templates/rule.template.md`를 복사해서 시작한다.

> 현재 이 폴더에는 실제 콘텐츠가 없다. Phase 1 콘텐츠 설계 단계에서 채운다.
