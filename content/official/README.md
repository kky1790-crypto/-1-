# content/official

`source_level: H1` (해피니언 공식) 또는 `H2` (사부님 심연/시면 전달 기준)
콘텐츠만 이 폴더에 둔다.

- H1: 해피니언 전체 공식 기준
- H2: 사부님이 심연/시면에서 직접 전달한 기준

강서 기준, 마곡점 기준, 강윤 개인 의견은 여기 두지 않는다
(각각 `content/gangseo`, `content/magok`, `content/ideas` 참고).

메타데이터 스키마는 `docs/DATA_MODEL.md`, 출처 규칙은
`docs/SOURCE_POLICY.md` 참고. 작성 시 `content/_templates/rule.template.md`를
복사해서 시작한다.

> 현재 이 폴더에는 실제 콘텐츠가 없다. Phase 1 콘텐츠 설계 단계에서 채운다.
